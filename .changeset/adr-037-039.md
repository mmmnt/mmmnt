Grammar completeness, palette conformance, project mode and sync (ADR-037, ADR-038, ADR-039).

**Grammar (ADR-037).** Projections with sources, description and fields; query declarations; context-level rules with a declared or external enforcer; value objects at the context level; per-context glossary terms; external systems as relationship ends and External lanes; policies triggered by a condition. Flow nodes resolve to projection and query kinds. Code generation emits read-model types for value objects, projections and queries; the specification document renders projections, queries, rules, terms and externals; the context map draws externals.

**Palette conformance and project mode (ADR-038).** The grammar is held to the NDD palette, and completeness rules V22–V28 check a model. Every read-only command, `serve --project`, and `reconcile` accept a model directory and load it as one merged project; project mode checks node placement, saga transitions and external lanes across files.

**Sync (ADR-039).** `sync propose` persists drift proposals in `.domain/`; `sync accept` and `sync reject` decide them with the deciding identity from git, record feedback in an append-only journal, and commit exactly the paths they name.

**Possibly breaking for existing models.** The palette and completeness rules can report errors on a model that previously parsed, and a merged project fails on any file's error. Run `moment parse <dir>` after upgrading.
