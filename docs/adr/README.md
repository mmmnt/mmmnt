# Architecture decision records

Each file here records one decision about the Moment language or its toolchain. This directory is the record.

- ADR-001 to ADR-036 (and ADR-001-A) were written in the private MMMNT Confluence space. They were migrated here on 2026-11-24 from an archive of that space taken on 2026-07-14. Their decision text is kept as written. Only the formatting changed. Each file names its Confluence page, version and last update.
- ADR-037 to ADR-039 were rebuilt on 2026-11-24. Their original documents did not survive. See [Gaps](#gaps).
- ADR-040 on were written in this directory.

Dates are the dates each ADR gives for itself. Where an ADR gives several, the first is shown. Statuses are as each ADR states them; an ADR migrated from Confluence keeps the status it had there, even when the code has since moved on.

## Gaps

- **ADR-032 was never written.** ADR-033 and ADR-034 cite it as "Project-Level Execution Model", and so do code comments (for example `ADR-032 R2` in `packages/core/src/project/project-loader.ts`). No page or file for it exists. The number stays unused so that those citations do not point at a different decision.
- **ADR-035 and ADR-036 are recovered summaries.** Both were renumbered in Confluence on 2026-04-20: ADR-035 was ADR-025, and ADR-036 was ADR-031. The renumbering edit lost their page bodies. What is here was recovered from page history and is short. Older pages cite them by their old numbers. [ADR-026](ADR-026-oauth-device-flow-github-app-authentication-for-moment-cli.md) cites ADR-035 as ADR-025, and its links point to ADR-035.
- **ADR-037 to ADR-039 are rebuilt.** Their original documents did not survive. Each was rebuilt on 2026-11-24 from PR #181, the 0.6.0 release notes, the old wiki ADR index and the code. Each says so at the top, and none states more than those sources support.
- **ADR-004 has no body.** The Confluence page says the original content is "preserved below", but the archived page holds only the supersession notice and the metadata.
- **ADR-033 lost a closing note.** The page ended with a note that was not part of the ADR (questions about where to file a ticket). It was removed during migration.

## Other ADR series

Migrated text also cites ADRs that are not in this directory. They are not Moment ADRs and are not linked:

- **Sift ADR-NNN** (for example Sift ADR-052) belong to Sift.
- **PADR-NNN** are platform ADRs shared by the Complai products.
- **FACET-ADR-NNN** (cited by ADR-031 and ADR-045) belong to Facet. No FACET-ADR file lives in this directory.

## Writing a new ADR

Take the next free number after the highest file here. Use the header style of the recent ADRs: `# ADR-NNN: Title`, then `- **Status:**` and `- **Date:**` lines. Add the new ADR to the index above.
